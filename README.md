## 📖 What Is Create Mod?

**Create** is a tech mod that reimagines automation in Minecraft. Rather than using electricity or magic, Create uses **rotational energy** — you build physical machines with gears, shafts, belts, and pistons that you can see working in real-time.

The mod is designed to be **visually satisfying** — every machine has animations, every mechanism feels physical, and nothing is hidden behind boring GUI screens. You see your factory work.

**Key highlights:**
- ✅ **Kinetic energy system** — RPM and Stress Units instead of electricity
- ✅ **Dynamic structures** — moving, rotating contraptions that interact with the world
- ✅ **Trains & Railways** — fully functional train systems with schedules
- ✅ **Beautiful animations** — every machine has visible moving parts
- ✅ **Ponder system** — built-in tutorial animations (press W on any item)
- ✅ **Decoration focus** — industrial aesthetic that looks great in builds

## ✨ Features

### ⚙️ Kinetic Energy System
- **Rotational Power** — Water wheels, windmills, hand cranks, steam engines
- **Stress Units (SU)** — Each machine consumes SU; overload and your network stops
- **Speed Control** — Gears change RPM; bigger gear → smaller gear = faster rotation
- **Shafts & Cogs** — Transfer rotation across your base
- **Gearboxes** — Change rotation direction and axis

### 🏭 Machine Processing

## ❓ FAQ

**Q: What is Create Mod?**
A: A tech and automation mod for Minecraft that uses rotational energy instead of electricity, with beautiful animated machines.

**Q: Is Create free?**
A: Yes — 100% free. You can include it in modpacks.

**Q: What Minecraft versions are supported?**
A: **1.18.2, 1.19.2, 1.20.1, and 1.21.1**. Older versions are discontinued.

**Q: Forge, NeoForge, or Fabric?**
A: Forge and NeoForge (1.20.1+), plus a dedicated Fabric port.

**Q: Do I need Flywheel?**
A: No — Flywheel is bundled inside Create 0.5.1c and newer. Older versions need it separately.

**Q: How do I learn Create?**
A: Press **W** while hovering over any Create item in your inventory to see a Ponder animation tutorial.

**Q: How does energy work?**
A: Create uses **Stress Units (SU)**. Each machine consumes SU. If you overload your network, everything stops.

**Q: What are the best power sources?**
A: Windmills and water wheels for early game; steam engines for late-game factories.

**Q: Can I make trains?**
A: Yes — Create has a full train system with tracks, schedules, and stations.

**Q: Do I need JEI?**
A: Recommended — it helps you see all Create recipes. Not required.

**Q: Does it work on Bedrock / mobile?**
A: No — **Java Edition only**.

**Q: Can I use it with other mods?**
A: Yes — Create works with JEI, FTB Chunks, JourneyMap, and many others.

**Q: How do I uninstall it?**
A: Delete the `.jar` from `.minecraft/mods/` and restart.

**Q: Where do I report bugs?**
A: Contact us via [minemods.top](https://minemods.top/)
